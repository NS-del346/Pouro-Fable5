# Pouro-Fable5

Mobile-first hand-drip brewing guide and timer PWA — implemented from the Claude Design / Fable5 prototype.

See [`docs/design/FABLE5_ARTIFACT_REPORT.md`](docs/design/FABLE5_ARTIFACT_REPORT.md) for the artifact inspection report and production implementation plan.

To preview the design prototype locally:

```sh
npx serve .
# then open: http://localhost:PORT/design-artifact/Pouro-Fable5.dc.html
# set viewport to 375 × 667
```
